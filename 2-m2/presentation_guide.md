# Подробный разбор всей программы (для презентации)

Этот документ — «скрипт доклада»: что делает программа, почему именно так, и как объяснить каждый этап уверенно и последовательно.

---

## 1. Что моделирует программа

Программа моделирует вакуумный диод (и упрощённый режим триода) по шагам:

1. **Этап 1**: рассчитывает распределение потенциала \(\phi(x)\) и поля \(E(x)\) между электродами.  
2. **Этап 2**: считает движение электронов в этом поле, **без взаимного влияния электронов**.  
3. **Этап 3 (опция)**: добавляет влияние собственного облака заряда (space-charge) через PIC-подобный цикл.  
4. **Этап 4**: строит ВАХ \(I(V_a)\), сравнивает с законом Чайлда–Лэнгмюра и проверяет степень \(3/2\).

Визуализация:
- большая объединённая страница с графиками этапов 1, 2 и 4;
- отдельная анимация движения электронов (если включена).

## 2. Структура проекта и роли файлов

## `params.json`
Главный набор параметров:
- физические константы;
- параметры эмиссии катода;
- геометрия диода/сетки;
- численные параметры;
- диапазон сканов по напряжению;
- настройки анимации.

Идея: **вся конфигурация вынесена в JSON**, чтобы менять режимы без правок кода.

## `config.py`
Загружает `params.json` и раскладывает по переменным модуля.  
Также содержит функцию:
- `emission_current()` — ток эмиссии по Ричардсону–Дэшману.

## `fields.py`
Отвечает за электростатику:
- построение сетки по \(x\),
- задание эффекта сетки как дополнительной фиксированной точки потенциала,
- решение 1D уравнения Пуассона,
- вычисление поля \(E=-\nabla\phi\),
- теоретическая формула Чайлда–Лэнгмюра.

## `simulation.py`
Основная динамика частиц:
- запуск электронов с тепловым разбросом скоростей,
- интегрирование движения в поле,
- учёт пересечения/блокировки на сетке,
- расчёт тока без взаимного влияния,
- PIC-подобный цикл с space-charge.

## `visualization.py`
Графики:
- `plot_combined_dashboard(...)` — общая страница этапов 1/2/4,
- `animate_electron_motion(...)` — «реалтайм»-анимация (ускоренное время).

## `main.py`
Оркестратор сценария:
- запускает базовый расчёт,
- запускает скан по \(V_a\),
- считает фит степени \(n\),
- строит дашборд и печатает численные результаты.

## 3. Полный путь вычислений (end-to-end)

## Шаг A. Загрузка параметров
При старте Python импортирует `config.py`, который читает `params.json`.

Ключевые параметры:
- `V_CATHODE`, `V_ANODE`, `V_GRID`;
- `GAP_LENGTH`, `GRID_POSITION`, `GRID_TRANSPARENCY`;
- `DT`, `T_END`, `N_TEST_PARTICLES`;
- `VA_SWEEP`, `RUN_SPACE_CHARGE`;
- параметры анимации.

## Шаг B. Базовый одиночный расчёт (этапы 1+2)
`main.py` вызывает:
```python
estimate_current_non_interacting(v_anode, v_cathode, v_grid, grid_enabled)
```
Внутри это делает:
1. `vacuum_field_solution(...)` из `fields.py`:
   - строится сетка `x`,
   - решается \(\phi(x)\),
   - считается `e = -gradient(phi)`.
2. `run_non_interacting(...)` из `simulation.py`:
   - создаётся ансамбль электронов у катода,
   - по шагам времени обновляются скорость и координата:
     \[
     v_{n+1}=v_n+\frac{q}{m}E(x_n)\Delta t,\quad x_{n+1}=x_n+v_{n+1}\Delta t.
     \]
3. Подсчёт:
   - доля дошедших до анода (collection efficiency),
   - ток \(I = I_{emission} \cdot \eta\),
   - средняя скорость на аноде.

## Шаг C. Анимация
Если включена:
- показываются частицы как точки,
- рисуется «хвост» последних положений,
- частица исчезает, если вышла за рабочий диапазон или была остановлена сеткой.

## Шаг D. Скан ВАХ (этап 4)
Цикл по `VA_SWEEP`:
- без space-charge: `estimate_current_non_interacting(...)`;
- с space-charge: `run_space_charge_pic(...)` (если включено).

Одновременно считается:
- теоретический ток по Чайлду–Лэнгмюру;
- «ограниченный» ток `i_sc = min(i_sc_raw, i_cl, emission_current())`, чтобы не выйти за физически разумные пределы в упрощённой модели.

## Шаг E. Проверка закона \(3/2\)
`_power_fit_langmuir(...)` делает логарифмический линейный фит:
\[
\ln I = n \ln V + b.
\]
Берётся верхняя часть диапазона напряжений (маска `quantile(0.45)`), после чего выводятся:
- `n` (ожидаемо близко к 1.5),
- `R²`.

## Шаг F. Построение итоговой страницы
`plot_combined_dashboard(...)` показывает 6 окон:
1. \(\phi(x)\),
2. \(E(x)\),
3. \(x(t)\),
4. \(v(t)\),
5. \(I(V_a)\),
6. \(\ln I\)–\(\ln V\) + линия фита.

## 4. Подробно про физику, которую реализует код

## 4.1 Электростатика
Используется 1D уравнение Пуассона:
\[
\frac{d^2\phi}{dx^2} = -\frac{\rho(x)}{\varepsilon_0}.
\]

- В «вакуумном» режиме: \(\rho=0\) (или заданные граничные условия).
- В space-charge: \(\rho(x)\) получается из распределения частиц.

## 4.2 Движение электрона
\[
m_e\dot v = qE,\quad q=-e.
\]
Поскольку \(q<0\), знак ускорения зависит от направления поля и положения в зазоре.

## 4.3 Роль сетки (упрощённый триод)
Сетка действует двумя способами:
1. как модификатор потенциала вблизи `GRID_POSITION` (через `build_triode_fixed_nodes`);
2. как вероятностный барьер прохождения:
   - часть электронов проходит по прозрачности `GRID_TRANSPARENCY`,
   - дополнительно проверяется кинетическая энергия против барьера \(V_c - V_g\).

Если электрон «не проходит», он останавливается в области сетки (в текущей модели это дискретное оседание на позиции сетки).

## 4.4 Space-charge в коде
Цикл на каждом шаге:
1. вброс новых макрочастиц от катода;
2. депонирование заряда на сетку `_deposit_charge_1d`;
3. решение Пуассона для новой \(\phi\);
4. пересчёт поля;
5. push частиц;
6. сбор тока на аноде.

Это приближённый PIC-подход (1D, без магнитных эффектов).

---

## 5. Что именно выводится в консоль

При запуске вы видите:
1. эмиссионный ток катода;
2. одиночный рабочий режим (ток, эффективность, скорость);
3. таблицу скана по \(V_a\):
   - `I_no_sc` — без space-charge,
   - `I_sc_raw` — прямой результат PIC,
   - `I_sc` — ограниченный (клип по теории/эмиссии);
4. параметры фита \(I \sim V^n\): `n` и `R²`.

Это удобно для «устной» презентации, т.к. графики и цифры согласованы.

## 7. На что обратят внимание на защите

1. **Почему ток ограничивается?**  
   Из-за собственного отрицательного заряда электронов (space-charge).

2. **Почему закон \(3/2\)?**  
   Это аналитический результат плоского диода в режиме SCL; численно проверяем через фит степени.

3. **Почему сетка иногда «останавливает» электроны в середине?**  
   Это следствие принятой модели сетки (прозрачность + энергетический барьер + дискретная блокировка).

4. **Почему `I_sc` и `I_sc_raw` различаются?**  
   `I_sc_raw` — прямой шумный/приближённый результат PIC,  
   `I_sc` — ограничение сверху физическими пределами (теория/эмиссия).

---

## 8. Ограничения и честные оговорки

Текущая реализация — инженерно-учебная, а не промышленный симулятор:
- 1D геометрия;
- простой интегратор по времени;
- упрощённая модель сетки;
- клиппинг тока для устойчивой физической интерпретации.

Для углубления обычно делают:
- 2D/3D PIC,
- более точные граничные условия реальной сетки,
- более строгую модель эмиссии/вторичной эмиссии,
- сеточную/шаговую сходимость как отдельный эксперимент.

## 9. Минимальный «короткий питч» (30–40 секунд)

«Программа решает задачу вакуумного диода по этапам: сначала поле \(\phi, E\), затем движение электронов, затем (опционально) самосогласованный space-charge. Дальше она строит ВАХ, сравнивает с Child–Langmuir и автоматически оценивает показатель степени в законе \(I\sim V^n\). В текущей версии всё сведено в один большой дашборд и отдельную анимацию, чтобы на защите было видно и физику, и численные результаты.»
